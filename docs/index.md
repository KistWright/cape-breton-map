# Cainnt is Ceathramhan  
### Map of People and Traditions

This project visualises informants and associated Scottish traditions linked to Cape Breton communities.

The repository contains:

- datasets describing people, places and traditions
- a Python script that generates the interactive map
- documentation explaining how the system works
